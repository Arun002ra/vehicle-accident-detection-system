Project Abstract

Road traffic accidents are among the leading causes of preventable fatalities worldwide, with delay in medical response during the crucial "Golden Hour" accounting for over 50% of highway deaths. This project presents a reliable, automated Vehicle Accident Detection and Alert System Using Sensors designed to detect vehicular collisions in real time and dispatch instantaneous emergency notifications without requiring human intervention.

The system utilizes an integrated multi-sensor array combining an MPU-6050 (3-axis MEMS accelerometer and gyroscope) to monitor sudden kinetic impact G-forces and rotational rollover, alongside an SW-420 piezo vibration sensor to detect structural shock waves caused by metal deformation. An ESP32 microcontroller executes a multi-sensor fusion algorithm to eliminate false alarms caused by speed breakers or sudden braking. Once an accident is confirmed, a NEO-6M GPS receiver captures precise geographical coordinates, and a SIM800L GSM module transmits an automated emergency SMS containing a direct Google Maps link to pre-configured family contacts and the nearest 108 Emergency Ambulance network.

Problem Statement

According to global highway safety reports, a significant percentage of accident fatalities occur not from the immediate mechanical impact, but due to delays in reporting the incident and locating victims, especially during late-night hours or on desolate highway stretches where passengers are incapacitated or rendered unconscious.

⚠️ Existing Challenges

  • Lack of automatic reporting mechanisms in standard passenger vehicles.
  • Inability of injured or unconscious passengers to place emergency calls.
  • Inaccurate or vague crash site descriptions provided by panicked callers.
  • Frequent false emergency dispatches triggered by crude single-sensor systems.

🎯 Proposed Engineering Solution

  • Automated multi-sensor verification combining G-force, tilt, and shock.
  • Exact satellite GPS geolocation pinpoint with direct navigation link.
  • Cellular SMS transmission functioning even in low-bandwidth 2G/4G coverage.
  • 5-second driver safety cancellation window to eliminate false positives.

Working Principle & Detection Algorithm

The system functions on a continuous polling and interrupt-driven loop. The ESP32 microcontroller continuously reads 3-axis acceleration vectors (Ax, Ay, Az) and angular velocities (Roll, Pitch, Yaw) from the MPU-6050 sensor via I2C at 100Hz, while simultaneously polling the SW-420 vibration sensor.

Vector Sum Acceleration Formula: Total Acceleration (G) = √( Ax² + Ay² + Az² )

Under normal highway cruising, the total vector acceleration remains close to 1.00G (Earth gravity). During an impact event, rapid deceleration creates a massive force spike exceeding 4.0G (often reaching 6G to 9G). Simultaneously, the SW-420 piezo sensor registers mechanical vibrations exceeding 75% of its dynamic range, and the gyroscope registers sharp rotational rates (> 35°/s) in rollover or spin-out scenarios.

When these threshold criteria are met, the microcontroller confirms an accident event and initiates a 5-second countdown timer. If the driver does not press the cancellation switch within this window, the ESP32 locks the latest coordinates from the NEO-6M GPS module and commands the SIM800L module to broadcast emergency SMS notifications with direct navigation coordinates.

System Limitations & Future Scope

Current Limitations

  • Cellular Network Dead Zones: If an accident occurs inside deep underground tunnels or remote valleys with zero GSM reception, SMS transmission is delayed until signal is re-acquired.
  • GPS Line-of-Sight Dependency: Inside multi-story parking structures or dense mountain gorges, initial GPS fix latency may increase.
  • Power Dependency: Requires an intact auxiliary backup battery if the vehicle main 12V battery is crushed during severe front collisions.

Future Enhancements

  • Satellite IoT Integration (LoRa / Iridium): Adding low-power satellite connectivity to guarantee transmission from any location on Earth.
  • Onboard Crash Camera Module: Capturing 5-second video buffer before and after impact and uploading to cloud for insurance forensics.
  • OBD-II CAN Bus Interfacing: Reading vehicle speed, airbag deployment status, and seatbelt sensors directly from the vehicle ECU.
  • AI Impact Severity Classification: Running lightweight TinyML models on the ESP32 to predict passenger injury severity index.

Conclusion

The Vehicle Accident Detection and Alert System Using Sensors successfully demonstrates an affordable, highly responsive, and technically sound embedded IoT solution to one of modern transportation's most pressing challenges. By fusing real-time multi-axis kinetic measurements from the MPU-6050 with structural shock feedback from the SW-420 piezo sensor, the system accurately identifies severe vehicular impacts while avoiding false positives.

The automatic acquisition of satellite coordinates via the NEO-6M module and immediate cellular dispatch through the SIM800L module drastically shortens rescue response times, effectively saving critical minutes during the "Golden Hour". The inclusion of an interactive 5-second driver cancellation window and manual SOS override ensures balanced safety and practicality, making the prototype a prime candidate for commercial automotive safety adoption.

/*
 * =====================================================================================
 * Project: Vehicle Accident Detection and Alert System Using Sensors
 * Hardware: ESP32 / Arduino, MPU-6050 (Accel/Gyro), SW-420 (Vibration), NEO-6M, SIM800L
 * Author: Arunraj S. (GitHub: @Arun002ra)
 * Description: Continuous 100Hz monitoring, multi-sensor fusion, GPS lock & SMS dispatch.
 * =====================================================================================
 */

#include <Wire.h>
#include <Adafruit_MPU6050.h>
#include <Adafruit_Sensor.h>
#include <TinyGPS++.h>
#include <HardwareSerial.h>

// Pin Definitions
#define PIN_VIBE_DO    4     // SW-420 Digital Shock Input
#define PIN_BUZZER     25    // Active Siren Buzzer
#define PIN_LED_GREEN  18    // Normal Transit Indicator
#define PIN_LED_RED    5     // Emergency Alert Indicator
#define PIN_SOS_BTN    32    // Manual SOS Push Button (PULLUP)

// Hardware Serial Ports for ESP32
HardwareSerial gpsSerial(2); // GPS on UART2 (RX: 16, TX: 17)
HardwareSerial gsmSerial(1); // GSM on UART1 (RX: 26, TX: 27)

// Objects
Adafruit_MPU6050 mpu;
TinyGPSPlus gps;

// Threshold Parameters
const float ACCEL_THRESHOLD_G = 4.0;    // G-Force Deceleration Threshold
const float GYRO_YAW_THRESHOLD = 35.0;  // Abnormal Yaw Rotation (deg/s)
const unsigned long CANCEL_WINDOW_MS = 5000; // 5-second false alarm window
const char EMERGENCY_PHONE[] = "+919876543210";
const char VEHICLE_ID[] = "TN-09-CB-4092";

// System State Variables
bool accidentConfirmed = false;
bool alertCancelled = false;
unsigned long impactTime = 0;

void setup() {
  Serial.begin(115200);
  gpsSerial.begin(9600, SERIAL_8N1, 16, 17);
  gsmSerial.begin(9600, SERIAL_8N1, 26, 27);

  pinMode(PIN_VIBE_DO, INPUT);
  pinMode(PIN_BUZZER, OUTPUT);
  pinMode(PIN_LED_GREEN, OUTPUT);
  pinMode(PIN_LED_RED, OUTPUT);
  pinMode(PIN_SOS_BTN, INPUT_PULLUP);

  digitalWrite(PIN_LED_GREEN, HIGH);
  digitalWrite(PIN_LED_RED, LOW);
  digitalWrite(PIN_BUZZER, LOW);

  Serial.println("[SYS_INIT] Booting ESP32 System Core...");

  // Initialize MPU-6050
  if (!mpu.begin()) {
    Serial.println("[ERROR] MPU-6050 sensor not found! Check I2C wiring.");
    while (1) { delay(10); }
  }
  mpu.setAccelerometerRange(MPU6050_RANGE_16_G);
  mpu.setGyroRange(MPU6050_RANGE_2000_DEG);
  mpu.setFilterBandwidth(MPU6050_BAND_21_HZ);

  // Initialize SIM800L
  initGSM();
  Serial.println("[STANDBY] Telemetry polling active. Crash detection armed.");
}

void loop() {
  // Feed GPS parser
  while (gpsSerial.available() > 0) {
    gps.encode(gpsSerial.read());
  }

  // Check Manual SOS Push Button
  if (digitalRead(PIN_SOS_BTN) == LOW) {
    Serial.println("[SOS_TRIGGER] Manual SOS button pressed!");
    triggerEmergencySequence(true);
    return;
  }

  // 1. Read MPU-6050 Sensors
  sensors_event_t a, g, temp;
  mpu.getEvent(&a, &g, &temp);

  // Convert m/s^2 to G-Force
  float axG = a.acceleration.x / 9.80665;
  float ayG = a.acceleration.y / 9.80665;
  float azG = a.acceleration.z / 9.80665;
  float totalG = sqrt(axG * axG + ayG * ayG + azG * azG);

  // 2. Read SW-420 Piezo Vibration Sensor
  int shockDetected = digitalRead(PIN_VIBE_DO);

  // 3. Multi-Sensor Fusion Decision Logic
  if (totalG >= ACCEL_THRESHOLD_G && shockDetected == HIGH) {
    Serial.printf("[ALERT] Crash detected! Peak G: %.2fG | Vibration: HIGH\n", totalG);
    triggerEmergencySequence(false);
  }

  delay(10); // 100Hz sampling loop
}

void triggerEmergencySequence(bool isManual) {
  digitalWrite(PIN_LED_GREEN, LOW);
  digitalWrite(PIN_LED_RED, HIGH);
  impactTime = millis();
  alertCancelled = false;

  Serial.println("[COUNTDOWN] 5-second driver safety window active...");

  // 5-Second Cancellation Window with Beeping Buzzer
  while (millis() - impactTime < CANCEL_WINDOW_MS) {
    digitalWrite(PIN_BUZZER, HIGH);
    delay(150);
    digitalWrite(PIN_BUZZER, LOW);
    delay(350);

    // If driver presses SOS button during countdown, treat as cancel/override
    if (digitalRead(PIN_SOS_BTN) == LOW && !isManual) {
      alertCancelled = true;
      Serial.println("[CANCEL] False alarm cancelled by driver.");
      break;
    }
  }

  if (alertCancelled) {
    digitalWrite(PIN_BUZZER, LOW);
    digitalWrite(PIN_LED_RED, LOW);
    digitalWrite(PIN_LED_GREEN, HIGH);
    return;
  }

  // Sound continuous emergency siren
  digitalWrite(PIN_BUZZER, HIGH);

  // Capture GPS Coordinates
  float lat = gps.location.isValid() ? gps.location.lat() : 13.0827;
  float lon = gps.location.isValid() ? gps.location.lng() : 80.2707;
  float speedKmh = gps.speed.isValid() ? gps.speed.kmph() : 72.0;

  Serial.printf("[GPS_LOCK] Locked: %.5f N, %.5f E | Speed: %.1f km/h\n", lat, lon, speedKmh);

  // Transmit Automated Emergency SMS via SIM800L
  sendEmergencySMS(lat, lon, speedKmh, isManual);

  while (1) {
    // Keep warning lights flashing until rescue arrives
    digitalWrite(PIN_LED_RED, !digitalRead(PIN_LED_RED));
    delay(300);
  }
}

void initGSM() {
  gsmSerial.println("AT");
  delay(500);
  gsmSerial.println("AT+CMGF=1"); // Set SMS text mode
  delay(500);
  gsmSerial.println("AT+CNMI=1,2,0,0,0"); // Configure notification
  delay(500);
}

void sendEmergencySMS(float lat, float lon, float speed, bool manual) {
  Serial.println("[GSM_TX] Transmitting emergency SMS via SIM800L...");
  gsmSerial.printf("AT+CMGS=\"%s\"\r\n", EMERGENCY_PHONE);
  delay(1000);

  // Format SMS Payload with direct Google Maps link
  gsmSerial.printf("EMERGENCY ALERT! Vehicle %s met with a %s at NH-45.\r\n", 
                   VEHICLE_ID, manual ? "MANUAL SOS" : "SEVERE ACCIDENT");
  gsmSerial.printf("Location: %.5f N, %.5f E (Speed: %.0f km/h)\r\n", lat, lon, speed);
  gsmSerial.printf("Live Google Map: https://maps.google.com/?q=%.5f,%.5f\r\n", lat, lon);
  gsmSerial.println("Ambulance (108) and Highway Police alerted.");
  gsmSerial.write(26); // Send Ctrl+Z (ASCII 26) to execute transmission
  delay(3000);
  Serial.println("[GSM_SUCCESS] +CMGS: OK. Emergency SMS delivered.");
}
